# 動画確認ページ（YouTube 版）

YouTube の動画を見ながら、止めた所にコメントを残すためのページです。アカウントもアプリも要りません。

## 見る人へ

1. 送られてきたリンクを開く（パソコンのブラウザがおすすめ）
2. 動画を再生して、直したい所で **Enter**（止まって、時刻が入ります）
3. 直したいことを書いて **Enter**（また再生が始まります）
4. 見終わったら右上の **「全部コピー」** を押して、LINE やメールに貼って送る

| キー | 動き |
|---|---|
| スペース | 再生・停止 |
| ← → | 1コマ戻る・進む（止めた状態で） |
| Shift ＋ ← → | 2秒戻る・進む |
| Enter | コメントを書く |
| Esc | コメントをやめて再生 |

- コメントはそのブラウザにだけ残ります。閉じても、同じブラウザで開けば続きからです。どこにも送られません。
- 一覧の時刻を押すとその場面へ飛びます。文はクリックで直せます。

## 作る人へ（リンクの作り方）

```
https://takahashi130.github.io/video-review/?v=<YouTube のリンクか動画ID>&title=<題>
```

| 項目 | 意味 | 例 |
|---|---|---|
| `v` | 見せる動画（必須） | `v=dQw4w9WgXcQ` |
| `title` | ページの題とコピーした文の見出し | `title=05_トラッシュバスターさん v004` |
| `fps` | ← → の1コマの長さ（省略時 29.97） | `fps=30` |
| `ch` | 区間ボタン（秒:名前 をカンマで） | `ch=0:アバン,95:本編,1060:HELP` |

- YouTube の動画は「限定公開」で、埋め込みを許可しておく（初期設定のままで可）。
- このリポジトリにはページの仕組みだけを置きます。番組の中身（字幕・文字起こし・動画）は置きません。

元の道具：Claude Code のスキル `video-review`（手元の動画ファイル用の確認ページ）。このページはその YouTube 版です。
