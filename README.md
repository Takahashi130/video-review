# 動画確認ページ（YouTube 版）

YouTube の動画を見ながら、止めた所にコメントを残すためのページです。アカウントもアプリも要りません。

## 見る人へ

1. 送られてきたリンクを開く（パソコンのブラウザがおすすめ）
2. 動画を再生して、直したい所で **Enter**（止まって、時刻が入ります）
3. 直したいことを書いて **Enter**（また再生が始まります）
4. 時刻のないこと（全体の決まり）は右の **「全体修正」** の欄へ
5. 見終わったら右上の **「送信」**。「送信」が無いページでは **「全部コピー」** を押して、LINE やメールに貼って送る

書き方に迷ったら、ページの「伝わりやすい書き方の例」を開いてください（例：「子守」→「子守り」／「なんか」音声ごとカット）。

止めている間は、画面に **ペン・矢印・四角・丸・文字** を描けます（色は黄・赤・白）。描いたものはコメントと一緒に残り、コピーした文にも入ります。

スマホでは「✎ 止めて書く」→ 文を書いて「追加」。画面には指で描けます。

🎤 を押して話すと、声が文字になります（Chrome・Edge・Safari・スマホ。Brave では使えません。声はブラウザの音声認識に送られて文字になります）。

| キー | 動き |
|---|---|
| スペース | 再生・停止 |
| ← → | 1コマ戻る・進む（止めた状態で） |
| Shift ＋ ← → | 5秒戻る・進む |
| Enter | コメントを書く |
| Esc | コメントをやめて再生 |

- コメントはそのブラウザに残ります。閉じても、同じブラウザで開けば続きからです。「送信」を押した時だけ、作り手の受け取り口（Google）に届きます。送ったものには ✓ が付きます。
- 「送信」があるページでは 🖼 で画像も付けられます（選ぶ・貼り付け・ドラッグ）。送る前にページで小さく縮めます。
- 一覧の時刻を押すとその場面へ飛びます。文はクリックで直せます。

## 作る人へ（リンクの作り方）

```
https://takahashi130.github.io/video-review/?v=<動画ID>
（短いリンクで足りる。題は YouTube の動画の題を自動で使う。&title=<題> や &ch=<秒>:<区間名>,… を足すこともできるが、リンクが長くなる）
```

| 項目 | 意味 | 例 |
|---|---|---|
| `v` | 見せる動画（必須） | `v=dQw4w9WgXcQ` |
| `title` | ページの題とコピーした文の見出し | `title=05_トラッシュバスターさん v004` |
| `fps` | ← → の1コマの長さ（省略時 29.97） | `fps=30` |
| `ch` | 区間ボタン（秒:名前 をカンマで） | `ch=0:アバン,95:本編,1060:HELP` |
| `to` | 送信先（受け取り口の URL。ページに決め打ちがあれば不要） | `to=https://script.google.com/macros/s/…/exec` |

- YouTube の動画は「限定公開」で、埋め込みを許可しておく（初期設定のままで可）。
- このリポジトリにはページの仕組みだけを置きます。番組の中身（字幕・文字起こし・動画）は置きません。

元の道具：Claude Code のスキル `video-review`（手元の動画ファイル用の確認ページ）。このページはその YouTube 版です。
