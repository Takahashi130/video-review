# Vcheck 動画確認ページ（YouTube 版）

YouTube の動画を見ながら、止めた所にコメントを残すためのページです。アカウントもアプリも要りません。

## 見る人へ

1. 送られてきたリンクを開いて、動画を再生する（スマホは最初に動画を直接タップ）
2. 直したい所で **「この場面にコメント」** を押す（止まって、その時刻が入ります）
3. 直してほしい内容を書いて **「追加」**
4. 見終わったら黄色の **「レビュー完了」** を押す（動画の作り手に届きます。何度押しても、新しく書いた分だけ届きます）

- メッセージで送りたい時は **「コメントを全てコピー」** を押して、相手へのメッセージに貼り付けてください。
- 動画の下の ⟲5・⟳5 で5秒戻る・進む。「使い方と詳しい操作」には、書き方の例・コマ送り・画面に描く道具（ペン・矢印・四角・丸・文字）があります。
- 入力欄の下のアイコン：クリップ＝画像を付ける、ペン＝画面に描く、マイク＝声で入れる（Chrome・Edge・Safari。Brave では使えません）。
- 時刻のないことは **「全体修正」** へ。名前は題の下の欄に入れるとコメントに付きます。
- コメントはそのブラウザに残ります（閉じても、同じブラウザで開けば続きから）。「レビュー完了」を押した時だけ届きます。
- パソコンのキー：スペース 再生・停止／← → 1コマ／Shift＋← → 5秒／Enter この場面にコメント（書いている時は追加）／Shift＋Enter 改行／Esc やめる

## 作る人へ（リンクの作り方）

```
https://takahashi130.github.io/video-review/?v=<動画ID>
（短いリンクで足りる。題は YouTube の動画の題を自動で使う。&title=<題> や &ch=<秒>:<区間名>,… を足すこともできるが、リンクが長くなる）
```

| 項目 | 意味 | 例 |
|---|---|---|
| `v` | 見せる動画（必須） | `v=dQw4w9WgXcQ` |
| `title` | ページの題とコピーした文の見出し | `title=05_トラッシュバスターさん v004` |
| `fps` | ← → の1コマの長さ（省略時 29.97） | `fps=30` |
| `ch` | 区間ボタン（秒:名前 をカンマで） | `ch=0:アバン,95:本編,1060:HELP` |
| `to` | 送信先（受け取り口の URL。ページに決め打ちがあれば不要） | `to=https://script.google.com/macros/s/…/exec` |

- YouTube の動画は「限定公開」で、埋め込みを許可しておく（初期設定のままで可）。
- このリポジトリにはページの仕組みだけを置きます。番組の中身（字幕・文字起こし・動画）は置きません。

元の道具：Claude Code のスキル `video-review`（手元の動画ファイル用の確認ページ）。このページはその YouTube 版です。
